かきますたべますしますきます

The ます form is the standard polite form used in everyday Japanese conversation, at work, and with people you don't know well. It expresses present tense ("I do") and future tense ("I will do").

TypeRuleExample
Ru-verbDrop る, add ます食べる → 食べます
U-verbChange final kana to い-row, add ます書く → 書きます
飲む → 飲みます
話す → 話します
するIrregularする → します
くるIrregular (vowel き)くる → きます

The い-row mapping for u-verbs: う→い, く→き, ぐ→ぎ, す→し, つ→ち, ぬ→に, ぶ→び, む→み, る→り

かきませんたべませんしませんきません

The polite negative uses the same verb stem as the ます form, but adds ません instead. It means "do not do" in polite speech. An alternative modern form is ない + です (e.g. 食べないです).

TypeRuleExample
Ru-verbDrop る, add ません食べる → 食べません
U-verbChange final kana to い-row, add ません書く → 書きません
飲む → 飲みません
するIrregularする → しません
くるIrregular (vowel き)くる → きません
かきましたたべましたしましたきました

The polite past expresses "did" in polite speech. It uses the same verb stem as the ます form, but adds ました.

TypeRuleExample
Ru-verbDrop る, add ました食べる → 食べました
U-verbChange final kana to い-row, add ました書く → 書きました
飲む → 飲みました
するIrregularする → しました
くるIrregular (vowel き)くる → きました
かきましょうたべましょうしましょうきましょう

The ましょう form means "let's do" in polite speech: 一緒に食べましょう (let's eat together). With か it offers or suggests: 窓を開けましょうか (shall I open the window?). Its plain equivalent is the volitional form (食べよう).

TypeRuleExample
Ru-verbDrop る, add ましょう食べる → 食べましょう
U-verbChange final kana to い-row, add ましょう書く → 書きましょう
飲む → 飲みましょう
するIrregularする → しましょう
くるIrregular (vowel き)くる → きましょう

The stem is the same as for ます: if you know 書きます, you know 書きましょう.

かいてたべてしてきて

The て form is one of the most important conjugations. It connects actions ("I ate and went home"), makes requests (〜てください), and is the basis for many grammar patterns like 〜ている (ongoing action), 〜てもいい (permission), and 〜てはいけない (prohibition).

TypeRuleExample
Ru-verbDrop る, add て食べる → 食べて
するIrregularする → して
くるIrregular (vowel き)くる → きて

U-verbs follow sound-change rules based on the dictionary-form ending:

EndingChangeExample
う, つ, る→ って買う → 買って、待つ → 待って、取る → 取って
む, ぶ, ぬ→ んで飲む → 飲んで、遊ぶ → 遊んで、死ぬ → 死んで
く→ いて書く → 書いて
ぐ→ いで泳ぐ → 泳いで
す→ して話す → 話して

Exception: 行く → 行って (not 行いて)

かかないたべないしないこない

The ない form is the plain/casual negative ("don't do"). It is used in casual speech and inside many grammar patterns like 〜ないでください (please don't), 〜なければならない (must do), and 〜ないと (if not).

TypeRuleExample
Ru-verbDrop る, add ない食べる → 食べない
U-verbChange final kana to あ-row, add ない書く → 書かない
飲む → 飲まない
話す → 話さない
するIrregularする → しない
くるIrregular (vowel こ)くる → こない

Exception: Verbs ending in う change to わ (not あ): 買う → 買わない

The あ-row mapping: く→か, ぐ→が, す→さ, つ→た, ぬ→な, ぶ→ば, む→ま, る→ら, う→わ

かいたたべたしたきた

The た form is the plain past tense ("did"). It follows the exact same sound-change rules as the て form, but uses た/だ instead of て/で. It is also used in the pattern 〜たことがある (have experienced).

TypeRuleExample
Ru-verbDrop る, add た食べる → 食べた
するIrregularする → した
くるIrregular (vowel き)くる → きた

U-verb sound changes (same pattern as て form, with た/だ):

EndingChangeExample
う, つ, る→ った買う → 買った、待つ → 待った、取る → 取った
む, ぶ, ぬ→ んだ飲む → 飲んだ、遊ぶ → 遊んだ
く→ いた書く → 書いた
ぐ→ いだ泳ぐ → 泳いだ
す→ した話す → 話した

Exception: 行く → 行った (not 行いた)

かかなかったたべなかったしなかったこなかった

The plain past negative means "didn't do." To form it, first make the ない form, then replace ない with なかった. This works the same way for all verb types since it builds on the ない form.

Typeない formなかった form
Ru-verb食べない食べなかった
U-verb (く)書かない書かなかった
U-verb (む)飲まない飲まなかった
U-verb (う)買わない買わなかった
するしないしなかった
くるこないこなかった

Think of it as: ない conjugates like an い-adjective (ない → なかった, just like 高い → 高かった).

かいたりたべたりしたりきたり

The たり form lists a few example actions, "things like": 週末は映画を見たり、本を読んだりします (on weekends I do things like watching movies and reading). The list ends with する, which carries the tense: 〜たりしました. One たり on its own means "and so on".

TypeRuleExample
All verbsMake the た-form, add り (だ → だり)食べた → 食べたり
書いた → 書いたり
飲んだ → 飲んだり
するした + りする → したり
くるきた + りくる → きたり

So the た-form sound changes all apply: 行く → 行ったり, 泳ぐ → 泳いだり.

かいたらたべたらしたらきたら

The たら conditional means "if" or "when / once": 雨が降ったら、行きません (if it rains, I won't go); 家に帰ったら、電話します (once I get home, I'll call). It is the most common "if" in everyday speech and works almost everywhere, even where ば or と would sound stiff.

TypeRuleExample
All verbsMake the た-form, add ら (だ → だら)食べた → 食べたら
書いた → 書いたら
飲んだ → 飲んだら
するした + らする → したら
くるきた + らくる → きたら

Compare: 〜ば (general "if", advice with ばいい), 〜と (always/automatically), 〜なら (if that's the case). The negative is なかったら: 食べなかったら.

かきたいたべたいしたいきたい

The たい form expresses the speaker's desire to do something ("I want to ~"). It uses the same stem as the ます form and adds たい. The たい form itself conjugates like an い-adjective (たくない, たかった, etc.).

TypeRuleExample
Ru-verbDrop る, add たい食べる → 食べたい
U-verbChange final kana to い-row, add たい書く → 書きたい
飲む → 飲みたい
するIrregularする → したい
くるIrregular (vowel き)くる → きたい

Only used for the speaker's own desires (first person). For third person, use 〜たがっている. The object particle を can optionally become が with たい.

かけるたべられるできるこられる

The potential form expresses ability — "can do" or "be able to." The result is a ru-verb, so it conjugates further like a ru-verb (e.g. 書ける → 書けない, 書けます).

TypeRuleExample
Ru-verbDrop る, add られる食べる → 食べられる
U-verbChange final kana to え-row, add る書く → 書ける
飲む → 飲める
話す → 話せる
するIrregular (completely changes)する → できる
くるIrregular (vowel こ)くる → こられる

In casual speech, ru-verb られる is often shortened to れる (ら抜き言葉): 食べられる → 食べれる. This is very common but considered informal.

The え-row mapping: う→え, く→け, ぐ→げ, す→せ, つ→て, ぬ→ね, ぶ→べ, む→め, る→れ

かこうたべようしようこよう

The volitional form expresses "let's do" or "I shall do." It is the plain equivalent of ましょう. It is also used with と思う to express intention (〜ようと思う = "I think I'll…").

TypeRuleExample
Ru-verbDrop る, add よう食べる → 食べよう
U-verbChange final kana to お-row, add う書く → 書こう
飲む → 飲もう
話す → 話そう
するIrregularする → しよう
くるIrregular (vowel こ)くる → こよう

The お-row mapping: う→お, く→こ, ぐ→ご, す→そ, つ→と, ぬ→の, ぶ→ぼ, む→も, る→ろ

かかれるたべられるされるこられる

The passive form means "is done (to someone)." Japanese passive has two uses: direct passive (the subject receives the action) and indirect/suffering passive (the subject is adversely affected). The result is a ru-verb.

TypeRuleExample
Ru-verbDrop る, add られる食べる → 食べられる
U-verbChange final kana to あ-row, add れる書く → 書かれる
飲む → 飲まれる
取る → 取られる
するIrregularする → される
くるIrregular (vowel こ)くる → こられる

Exception: U-verbs ending in う change to わ: 買う → 買われる

Note: ru-verb passive (られる) looks identical to the potential form. Context determines which meaning is intended.

かかせるたべさせるさせるこさせる

The causative form means "make someone do" or "let someone do." Whether it means forcing or allowing depends on context and the particles used. The result is a ru-verb.

TypeRuleExample
Ru-verbDrop る, add させる食べる → 食べさせる
U-verbChange final kana to あ-row, add せる書く → 書かせる
飲む → 飲ませる
読む → 読ませる
するIrregularする → させる
くるIrregular (vowel こ)くる → こさせる

Exception: U-verbs ending in う change to わ: 買う → 買わせる

"Make": 先生は学生に本を読ませた (The teacher made the students read a book.)
"Let": お母さんは子供にゲームをさせた (Mom let the child play games.)

かけばたべればすればくれば

The ば conditional means "if ~." It expresses general or hypothetical conditions. It is often used for advice (〜ばいい = "it would be good if") and habitual conditions.

TypeRuleExample
Ru-verbDrop る, add れば食べる → 食べれば
U-verbChange final kana to え-row, add ば書く → 書けば
飲む → 飲めば
話す → 話せば
するIrregularする → すれば
くるIrregularくる → くれば

Compare with other conditionals: 〜たら (more concrete/sequential), 〜と (automatic/natural result), 〜なら (topic-based condition).

かかせられるたべさせられるさせられるこさせられる

The causative-passive means "to be made to do" — the subject is forced to do something against their will. It combines the causative and passive forms. The result is a ru-verb.

TypeRuleExample
Ru-verbDrop る, add させられる食べる → 食べさせられる
U-verbChange final kana to あ-row, add せられる書く → 書かせられる
飲む → 飲ませられる
するIrregularする → させられる
くるIrregular (vowel こ)くる → こさせられる

Short form (u-verbs only): In casual speech, u-verbs use a contracted form: あ-row + される instead of せられる.
書く → 書かされる、飲む → 飲まされる、行く → 行かされる

Exception: U-verbs ending in す cannot use the short form (話す → 話させられる only, not 話さされる).

かけたべろしろこい

The command form (imperative) is a blunt order: "Do it!" It is rough and direct, so you hear it from coaches and fans (頑張れ!), in emergencies (逃げろ!), on signs, in manga and anime, and from older men to their family — but you would almost never say it to a stranger or your boss. To ask nicely, use 〜てください instead.

TypeRuleExample
Ru-verbDrop る, add ろ食べる → 食べろ
逃げる → 逃げろ
U-verbChange final kana to え-row書く → 書け
止まる → 止まれ
待つ → 待て
するIrregularする → しろ
くるIrregular (vowel こ)くる → こい

Exception: くれる → くれ ("give me"), and the honorific verbs end in い: くださる → ください, いらっしゃる → いらっしゃい, なさる → なさい.

The opposite, "don't!", is the dictionary form + な: 動くな (don't move!). Written orders and signs often use せよ for する (注意せよ). A softer command, used by parents and teachers, is the stem + なさい: 食べなさい.

かくなたべるなするなくるな

The prohibitive is a blunt "don't!", the negative of the command form: 動くな (don't move!), 忘れるな (don't forget!). Like the command form it is rough, so you see it on signs (触るな, 押すな), in notes to yourself, in manga and in emergencies. To ask nicely, use 〜ないでください.

TypeRuleExample
All verbsDictionary form + な食べる → 食べるな
書く → 書くな
騒ぐ → 騒ぐな
するする + なする → するな
くるくる + なくる → くるな

Careful: this な is not the soft な of 〜なさい (食べなさい = "eat up"), which is a command, not a ban.

かかずたべずせずこず

The ず form is a written, slightly formal "not". Most often it comes as ずに, "without doing": 朝ご飯を食べずに学校へ行った (I went to school without eating breakfast). It means the same as 〜ないで, and is common in writing, news and set phrases (思わず = "without thinking").

TypeRuleExample
Ru-verbDrop る, add ず食べる → 食べず
U-verbChange final kana to あ-row, add ず (like ない)書く → 書かず
買う → 買わず
するIrregularする → せず (not しず)
くるIrregular (vowel こ)くる → こず

An easy way to get it: take the ない form and swap ない for ず (食べない → 食べず), except that しない becomes せず.
