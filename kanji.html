Printable JLPT Kanji Practice Sheets

Free, printable PDF worksheets for testing kanji recall, one set per JLPT level from N5 (beginner) through N1 (advanced), in both directions. The practice sheet shows each kanji's English meaning with an empty box below it to write the kanji from memory. The meaning-practice sheet flips it around — the kanji is shown, and you write its meaning on ruled lines below. A matching answer key (kanji and meaning together, same order) covers both directions. Kanji are ordered to match the Benkyo app for N5/N4, and by Japanese school grade level (simplest first) for N3–N1.

  • N5 kanji: practice, meaning practice, answer key — 80 kanji
  • N4 kanji: practice, meaning practice, answer key — 167 kanji
  • N3 kanji: practice, meaning practice, answer key — 367 kanji
  • N2 kanji: practice, meaning practice, answer key — 367 kanji
  • N1 kanji: practice, meaning practice, answer key — 1,232 kanji

Printable Hiragana & Katakana Practice Sheets

Free printable PDF writing sheets for hiragana and katakana. Covers all 104 characters per script: the full gojūon, dakuten/handakuten, and yōon combinations.

  • Hiragana: practice, answer key — 104 characters
  • Katakana: practice, answer key — 104 characters

Printable Common Hiragana & Katakana Word Sheets

Free printable PDF worksheets for common whole words, one level up from single characters. Each item shows the word's romaji and English meaning; you write the word itself in hiragana or katakana on the ruled line below. The answer key prints the question (romaji + meaning) first and the word's kana spelling below it, same order as the worksheet.

  • Common Hiragana Words: practice, answer key — 49 words
  • Common Katakana Words: practice, answer key — 250 words

Printable Translation Worksheets by Grammar Point

Free printable PDF worksheets for practicing Japanese grammar through translation, one set per grammar chunk from N5 to N3 — from です sentences and polite verbs to keigo, passive and causative, 19 chunks in all. Each has 20 example sentences that use it, drawn from the same bank as the Sentences flashcard mode. The "to English" sheet shows the Japanese sentence (with furigana) and ruled lines to write the English translation; the "to Japanese" sheet shows the English sentence and ruled lines to write the Japanese. Each has its own answer key, printing the question first and its answer below, in the same order as that sheet.
