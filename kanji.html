Printable JLPT Kanji Practice Sheets

Free, printable PDF worksheets for testing kanji recall, one set per JLPT level from N5 (beginner) through N1 (advanced), in both directions. The practice sheet shows each kanji's English meaning with an empty box below it to write the kanji from memory. The meaning-practice sheet flips it around — the kanji is shown, and you write its meaning on ruled lines below. A matching answer key (kanji and meaning together, same order) covers both directions. Kanji are ordered to match the Benkyo app for N5/N4, and by Japanese school grade level (simplest first) for N3–N1.

Printable Common Hiragana & Katakana Word Sheets

Free printable PDF worksheets for common whole words, one level up from single characters. Each item shows the word's romaji and English meaning; you write the word itself in hiragana or katakana on the ruled line below. The answer key prints the question (romaji + meaning) first and the word's kana spelling below it, same order as the worksheet.

  • Common Hiragana Words: practice, answer key — 49 words
  • Common Katakana Words: practice, answer key — 250 words

Printable Translation Worksheets by Grammar Point

Free printable PDF worksheets for practicing Japanese grammar through translation, one set per grammar point from Genki I & II (roughly N5 and N4) — 23 grammar points in all, including the copula and demonstrative basics from chapters 1-2 that precede verb conjugation. Each grammar point has 20 example sentences that use it, drawn from the same bank as the Sentences flashcard mode. The "to English" sheet shows the Japanese sentence (with furigana) and ruled lines to write the English translation; the "to Japanese" sheet shows the English sentence and ruled lines to write the Japanese. Each has its own answer key, printing the question first and its answer below, in the same order as that sheet.
